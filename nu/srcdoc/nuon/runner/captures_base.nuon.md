# captures_base.nuon

Maps' poses captured on a set of images. The long engine's body alone: the
harness made ready by `nuance.nu runner ready captures_base`, then its work
launched as `nuance.nu runner work captures_base` with the progress check and
the bounds, `stress` the workbench's checkout, whose bin both run.

Its arguments past `stress`, `label`, and `mcp_nom`: `nuance` the pose bin,
`nu/bin/nuance/fierce/pose.nu`, `kernel` the kernel every capture boots, `root`
the captures' directory, `sets` each set's name and image, `maps` each map and
its poses file.
