# route_battery.nuon

The routes' battery on a debug image. The long engine's body alone: the harness
made ready by `nuance.nu runner ready route_battery`, then its work launched as
`nuance.nu runner work route_battery` with the progress check and the bounds,
`stress` the workbench's checkout, whose bin both run.

Its arguments past `stress`, `label`, and `mcp_nom`: `fps`, `base`, `image` the
debug image every batch runs, `runs`, `batches` each batch's label, route, and
workers, -1 for the automatic.
