# pixel_identity.nuon

Sets' captures of maps' poses held pixel for pixel to a base set's. The long
engine's body alone: the harness made ready by `nuance.nu runner ready
pixel_identity`, then its work launched as `nuance.nu runner work
pixel_identity` with the progress check and the bounds, `stress` the workbench's
checkout, whose bin both run.

Its arguments past `stress`, `label`, and `mcp_nom`: as captures_base's, `base`
the set every other set is held to.
