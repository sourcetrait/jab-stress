# consumers.nuon

The readers of landed runs and the inputs each requires, which `runner
record required` holds a restoration to. The table names the rereads that
read through a restoration today: the sdl probe's controls reread, which
requires the controls' record and the monolithic control's shim log and
flush trace. Its other inputs, the modular and stripped controls' logs, are
read where they are there, so they are not required. ProbeRuns' reader,
`fps proberuns`, requires a batch's report and each run's capture,
identity, route, and bundle manifest, at any depth under the tree, so a run
landed as one battery or as several reads alike. Each reader that comes to
read through a restoration adds its rows here.
