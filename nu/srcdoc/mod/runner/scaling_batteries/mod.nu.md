# mod.nu

The scaling_batteries runner's code, reached by its descriptor through the
workbench bin's `runner` verbs, or run whole by `do.nu bench scaling_batteries
<args>`.

## def ready

Before the launch: refuses any battery's base that exists or a missing image;
returns the six batteries' names, bases, and batch counts.

## def main

The work: GfxScaling: on three, four, and eight harts over the settled and
factory routes, the base image on three, the automatic selection, and each
forced count, then reversed, three runs each with their CPU; each battery's
fields compared, diagnostic but on three harts; returns each battery's batches
and compares.
