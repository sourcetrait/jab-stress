# mod.nu

The two_build_battery runner's code, reached by its descriptor through the
workbench bin's `runner` verbs, or run whole by `do.nu bench two_build_battery
<args>`.

## def ready

Before the launch: refuses a `base` that exists or a named image missing, then
makes `base`.

## def main

The work: each batch fierce built release and run on its image and the route,
then each field compared; returns the batches done and the compares.
