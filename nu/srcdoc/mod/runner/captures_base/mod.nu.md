# mod.nu

The captures_base runner's code, reached by its descriptor through the workbench
bin's `runner` verbs, or run whole by `do.nu bench captures_base <args>`.

## def ready

Before the launch: refuses a set's directory under `root` that exists, then
makes `root`.

## def main

The work: every set's maps captured by the pose bin, sets outermost, a log a set
and map; each screen's SHA-256 a row of `base_captures.nuon`; returns the count
and the exits.
