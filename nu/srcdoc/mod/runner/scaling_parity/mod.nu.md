# mod.nu

The scaling_parity runner's code, reached by its descriptor through the
workbench bin's `runner` verbs, or run whole by `do.nu bench scaling_parity
<args>`.

## def ready

Before the launch: refuses a `base` that exists, then makes it.

## def main

The work: each step's parity or fault by the bin into `<base>/<name>`, its log
beside; returns ok when every step's verdict is, and each step's exit and
verdict.
