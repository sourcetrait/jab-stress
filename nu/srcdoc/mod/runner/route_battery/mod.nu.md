# mod.nu

The route_battery runner's code, reached by its descriptor through the workbench
bin's `runner` verbs, or run whole by `do.nu bench route_battery <args>`.

## def ready

Before the launch: refuses a `base` that exists or a missing image, then makes
`base`.

## def main

The work: each batch fierce built debug and its gauge run on the image, its
route and workers; returns the batches done.
