# mod.nu

The captures' hook: a map's poses captured on an image by the pose bin,
`nu/bin/nuance/fierce/pose.nu`, which `poses.just`'s `pose-map` was, and each
screen's SHA-256 a row.

## def shot

- `<root>/<set>/<map>/<pose>/screen.ppm` each screen, the run's output
  `<root>/<set>_<map>.log`
- a row `{set, map, pose, capture, exit}`, the exit the bin's for every row of
  the call

## def by-set

Every set's maps, sets outermost, the order captures_base and
captures_compare record; pixel_identity runs maps outermost through `shot`.

## def fresh

A set's directory under `root` that exists refuses the battery, so no capture
lands over another's.
