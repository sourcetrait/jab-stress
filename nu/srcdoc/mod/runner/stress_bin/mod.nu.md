# mod.nu

The stress_bin runner's code, reached by its descriptor through the workbench
bin's `runner` verbs, or run whole by `do.nu bench stress_bin <args>`: a
workbench bin's verb past a tool call's bound, the qualification's `check`
among them.

## def ready

Before the launch: the bin `nu/bin/<bin>.nu` found in the workbench, the log's
directory made.

## def main

The work: the workbench's `nu/bin/<bin>.nu <verb> <words>` from its root under
the environment given, its whole output saved; a non-zero exit an error;
returns the exit and the last lines.
