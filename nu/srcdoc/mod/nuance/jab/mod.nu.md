# mod.nu

The workbench's reach into jab's casual driver, the sibling checkout's
`nu/bin/do.nu`, run in a nu of its own as `nu <do.nu> <verb> <dir> --set
<symbols>`, the form the recipes used. A directory by its absolute path is the
driver's subject (`workspace subject`): a candidate's export, built by the live
checkout's SDK. Its verbs: `nu/bin/nuance.nu build|test <dir> --set <symbols>`.

## def build

- the symbols comma separated; a release candidate's recipe passed
  `release` among them, which the verb passes on as given

## def test

- the program's tests at `dir` with the symbols named, `DEBUG` added by the
  driver, every program's test and the pass table its output
