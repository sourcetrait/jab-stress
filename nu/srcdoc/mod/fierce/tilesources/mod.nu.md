# tilesources/mod.nu

How a compiled map tree named its tiles' sources before jab c804ccb, for a
tree made again today and held to one compiled then.

## def rooted

The tree's tile.nuon naming each source under `content`, as a checkout
compiled it before jab c804ccb: the compiler named the content's absolute
path there, and names each source relative to the content since, so a tree
compiled today differs from one compiled then in that file alone. An empty
source, a material the content lacked, stays empty.
