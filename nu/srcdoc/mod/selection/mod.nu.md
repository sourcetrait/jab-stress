# mod.nu

What a host's renders select of a probed run's paired uploads, the rules
sdl-report reads a window by, shared by ProbeRuns' reader
(`nu/mod/fierce/proberuns`) and walk's paired reading
(`nu/mod/kernel/walk`), so the two workloads are read by one rule.

## def stamp-us

A log stamp, the shim's seconds and six digits, as whole microseconds, so a
host interval is exact.

## def main

`selection <events> <pairs>`: the log's events in order, a checked bundle's
(`sdl bundle-check`), its flip uploads numbered from 1 as the pairing numbers
them; each render selects the latest upload before it, the one SDL's texture
holds, and its gap is the time since the render before. For each pair, an
`ordinal` and its `upload_us` as `sdl pair` returns them, in the pairs'
order: its upload's stamp and the interval since the pair before's upload;
the renders selecting it; shown where one does, superseded where none does
and a later render does, unshown at the end where no render follows; its
repeats, the renders past the first; its age at the first render that shows
it, both host stamps; the interval since the shown pair before, between
their first renders; and its renders' gaps. Returned with the count of
renders.
