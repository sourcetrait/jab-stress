# mod.nu

JointTiming's host package (HostPackage, step 5): the frozen exports a
readings spec names by role, the asset tree and the route every fps run of
the comparison played, and jab's bench a target, laid by jab's `package`
module into one tar, so TheUser's host runs the box's guest bytes and builds
nothing. Its bin: `nu/bin/nuance/kernel/timing.nu package <spec> <out>`,
`--stage` the staging directory, beside `out` unless given.

## const JAB

jab beside the workbench: its benches, `kit/fierce/bench/jointtiming_<t>.nuon`,
are packaged as committed, refused when they differ from its commit.

## const TARGETS

The targets a bench is written for, 1KA1 and 1KB1, one bench each, so a host
runs the targets it can provision.

## const PACKAGED

The guest inputs' places in the package, the paths the benches name under
`{package}`: fps's image and its build's files beside it, P0's and P2's
kernels, walk's four CADENCE images each in a directory of its own with the
`flags` and `walk.romfs` the wrapper reads beside it, the asset tree, and
the route.

## def held

A file held to a SHA-256, refused by name otherwise.

## def frozen

A frozen export's file by its role in the spec's freeze, refused when the
freeze names none or it is not on disk.

## def played

The first fps run's identity among the spec's batteries: the asset tree and
the route the comparison's runs played, which the package carries held to
their recorded digest and SHA-256.

## def main

The package: fps's image with its ELF, flags, demand, provenance, and source;
each kernel as `kernel`, its rule, ELF, and loaded identity its meta, its
provenance beside it; walk's images, flags, disks, and provenance; the asset
tree held to the runs' digest; the route held to their SHA-256; both benches
from jab's committed tree. Its manifest's identities name the freeze's roles
by SHA-256, fps's commit, the assets, the route, and the benches' commit. The
package is named for jab's commit, and its inputs and stage are written once.
