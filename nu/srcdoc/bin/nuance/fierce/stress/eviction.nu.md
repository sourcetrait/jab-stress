# eviction.nu

The eviction module's command line, each verb one call of the module, standalone so its closures run in a nu that loads no other module.

## def main

`nu/bin/nuance/fierce/stress/eviction.nu`, its parameters `kernel: path, image: path, disk: path, out: path, ...fixtures: string`: the eviction fixtures named, every one by default, each result kept.
