# grainpairs.nu

The grainpairs module's command line, each verb one call of the module,
standalone so its closures run in a nu that loads no other module.

## def main

`nu/bin/nuance/fierce/grainpairs.nu`, its parameters `mode: string, base:
string, out: string, a: string, b: string, count: int`: A battery's two band
heights read as matched pairs, saved and printed.
