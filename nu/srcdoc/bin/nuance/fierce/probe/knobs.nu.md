# knobs.nu

The knobs module's command line, each verb one call of the module, standalone so its closures run in a nu that loads no other module.

## def main

`nu/bin/nuance/fierce/probe/knobs.nu`, its parameters `mode: string, out: path, --seconds: int = 10`: the pool's knobs probed in one mode on the debug build, probe.nuon kept.
