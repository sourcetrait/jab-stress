# pair.nu

The pair module's command line, each verb one call of the module, standalone so its closures run in a nu that loads no other module.

## def main

`nu/bin/nuance/fierce/probe/eviction/pair.nu`, its parameters `pair: path, sets: path, a: int = 0, b: int = 4`: a pair run's dumps read against a views run's key sets, printed as NUON.
