# oblique.nu

The oblique module's command line, each verb one call of the module, standalone so its closures run in a nu that loads no other module.

## def main

`nu/bin/nuance/fierce/probe/handoff/oblique.nu`, its parameters `kernel: path, image: path, disk: path, out: path, spec: string`: the oblique pose's held, tiled, and partial runs at each level.
