# oblique.nu

The oblique module's command line, each verb one call of the module, standalone
so its closures run in a nu that loads no other module.

## def main

`nu/bin/nuance/fierce/probe/handoff/oblique.nu`, its parameters `kernel: path,
image: path, disk: path, out: path, spec: string`: The oblique pose's held,
tiled, and partial runs at each level.

## def main on-debug

`nu/bin/nuance/fierce/probe/handoff/oblique.nu on-debug`, its parameters `spec:
string, disk: path, out: path`: The oblique probe on jab's debug kernel and
image over a handoff map's disk.
