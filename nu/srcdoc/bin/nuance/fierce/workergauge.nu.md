# workergauge.nu

The workergauge module's command line, each verb one call of the module,
standalone so its closures run in a nu that loads no other module.

## def main

`nu/bin/nuance/fierce/workergauge.nu`, its parameters `mode: string, base:
string, out: string, ...labels: string`: WorkerGauge's reading saved to `out`
and summarised.
