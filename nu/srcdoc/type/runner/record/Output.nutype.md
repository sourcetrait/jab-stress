# Output.nutype

The shape of the output table, `nu/nuon/runner/record/outputs.nuon`: a row
for each reader's output a landing holds to its model, the output's glob
relative to the run, the sets it lands in as `<subject>/<set>` (none for
every set), the checkout its model sits in, `jab-stress` or `jab`, and the
model's path in that checkout.
