# Restoration.nutype

The receipt of a restoration, `restoration.nuon`, written beside the tree
the restore lays out. It names the landed run it was made from, the
SHA-256 of the inventory and the storage it read, every original
reconstructed with its SHA-256 and the stored object it came from, and
every original not reconstructed with its disposition. A run of schema 1
restores as a copy, so its receipt names no inventory or storage, both
null.
